# Claude Code + Compound Engineering

Inside Claude Code:

```text
/plugin marketplace add EveryInc/compound-engineering-plugin
/plugin install compound-engineering
```

Restart Claude Code if required.

Then run inside this repository:

```text
/ce-setup
```

For a normal feature:

```text
/ce-brainstorm <feature>
/ce-plan
/ce-work
/ce-simplify-code
/ce-code-review
/ce-test-browser
/ce-compound
```

Enterprise rule:

> AI prepares changes. Humans approve and merge.
